# POP'n WASH Wavre

Site officiel moderne et multilingue de la laverie POP'n WASH Wavre.

- Hébergement prévu : GitHub Pages
- Déploiement automatique à chaque push sur `main`
- Responsive mobile / desktop
- Langues : FR, NL, EN, DE, IT, ES, PT, RO, PL, UK, RU
- WiLine : suivi des machines, notification de fin de cycle et factures
- Contact : +32 486 999 251 · ahb.lavoir@gmail.com

## Publication

Le workflow `.github/workflows/deploy-pages.yml` publie automatiquement le site après l'activation initiale de GitHub Pages dans **Settings → Pages → Source → GitHub Actions**.
